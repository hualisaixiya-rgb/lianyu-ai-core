## 一、冻结原则

V3.8 是 V3 系列的最终稳定版本。以下模块**冻结**——不再接受除安全修复外的任何修改。

冻结不意味着代码完美，而是当前状态已经过充分测试和验证，继续修改得不偿失。所有改进留给 V4。

## 五、V3.8 基线不可变项

以下项目在 V3.8 基线中**不应被修改**——任何修改都意味着需要切换到新基线：

1. **Persona 表达层**（system.yaml + eryi.yaml 的 personality/speaking_style 字段）
2. **Memory 存储层**（所有 Store 的表结构和 CRUD 逻辑）
3. **Intent 检测**（5 种意图 + 关键词规则）
4. **Pending Identity 三级回退**（confirmed → candidate → none）
5. **LLM Provider**（API 调用参数 model/temperature/max_tokens）
6. **Telegram Bot**（适配器逻辑）

---

## 六、基线切换流程

当 V4 Stage 0 完成后，创建 `v4.0-core-split` tag。届时 `v3.8-stable` 进入归档状态。

```
V3.8 基线（当前）
  ↓ V4 Stage 0 完成
V4.0-base（新基线）
  ↓ V4 Stage 1-6 逐步完成
V4.x-stable
```
