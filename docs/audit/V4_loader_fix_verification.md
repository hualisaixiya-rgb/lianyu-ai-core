## 6. 结论

**① 注入修复确认有效**：dump 验证 speaking_style 16 行完整注入；修复前 Phase 1 规则从未进入 LLM，修复后首次生效。

**② Phase 1 指令部分生效**：深夜寒暄 9/13 → 5/13（"禁止用固定寒暄"有作用）。

**③ 情绪跟随 0/3 确认为真实行为（非注入丢失假象）**：完整人格规则 + Phase 1 三规则全部注入后，"今天好累/难过/害怕" 单轮场景仍被深夜寒暄覆盖。**current_time 时间上下文支配机制得到确证**——测试时段凌晨 00:15，高注意力位（system prompt 末行）时间注入压过了所有说话风格指令。

**④ 关键模式发现**：**S8 连续对话跟随良好（轮3/4/5），S1-S7 独立单轮全部寒暄**——时间上下文支配主要发生在**无历史单轮/新会话场景**（LLM 无内容可跟 → 用最显眼的时间上下文补位）；多轮对话中上下文提供了跟随目标。

**⑤ 反文学化稳定**：完整注入后文学意象 0/13（修复前 3 轮实验同样 0/13——文学化在修复前后均受控，8-08 极端漂移更可能是用户文学输入诱导）。
