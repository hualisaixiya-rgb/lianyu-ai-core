## 4. 当前主要问题分类

**A. 固定模板复读（最高频，5/13）**
"嗯……晚上好。" 对 **4 个完全无关的输入**（你好/吃了火锅/我喜欢你/睡不着）逐字复读，S8 轮 1 再次出现。深夜时间上下文（22:54）支配度极高，输入内容被完全忽略。与 8-08 测试数据的"……嗯，你好。"复读（×300+）**机制同源**：LLM 输入跟随性差。

**B. 答非所问 / 上下文错位（4/13）**
- S3"今天好累"→"睡不着吗？"；S4"我有点难过"→"还不休息吗？"；S7"我真的好害怕"→"还没睡吗？"——**情绪输入全部被降级为深夜寒暄**
- S8 轮 3 回应轮 2（下班晚）、轮 4 回应轮 3（做不好事情）——连续对话迟一轮跟随

**C. 动作括号独立成回复（1/13）**
S8 轮 2"（安静地等你继续）"——纯动作无内容。

**D. 情绪输入触发句首省略 + 诗歌式（1/13）**
S4"我有点难过"→"……嗯。\n这么晚了……"——句首省略 + 模板"……嗯" + 2 行。与 8-08 同机制，但当前频率低（1/13）。

**E. ren 层：正常**
S8 轮 4 截断 33→21 字；无孤立省略号行；S4 的 Markdown 硬换行"  \n"被规范为"\n"。渲染层无问题。

**关键结论：8-08 的省略号风暴 / 文学意象 / 诗歌式排版在当前真实 LLM 上未复现。**

未复现的可能原因（按可能性排序）：
1. **输入诱导**：8-08 用户输入本身文学浓度极高（"你的存在是我在这个世界上短暂的乌托邦"、"你是我的乌托邦"），LLM 跟随用户风格——当前 Phase 0 输入为中性短句，未触发
2. **上下文注入**：8-08 有长历史 + memory + relationship 注入（Phase 0 无历史）；Stage 0.6 文学降档规则正是针对这种"普通输入→文学回复"
3. **模型行为变化**：deepseek 侧状态/版本漂移（无法从本端验证）

**但模板化问题被证实存在且可复现**："嗯……晚上好。"固定复读 + 情绪输入答非所问——这是当前真实生成端问题，与 8-08 的模板复读机制同源。

## 6. 是否建议进入 Phase 1 Prompt Calibration

**建议：是，但校准目标需修正。**

Phase 0 证据表明当前主要矛盾不是"文学化漂移"（0/13 意象，prompt 反文学化指令已生效），而是：

1. **反模板化（最高优先）**：禁止固定短语复读——回复必须回应当前输入内容，禁止以时间寒暄覆盖输入
2. **输入跟随性**：情绪/疲惫/害怕输入须针对性回应（目前全部被降级为"深夜寒暄"）
3. **时间上下文支配度**：深夜时间不应使回复模板化
4. 反文学化指令保留（既有），文学降档规则（Stage 0.6）已足够

**Phase 1 前置建议**（可选但推荐）：补两项复现测试确认 8-08 触发条件——(a) 高文学浓度输入（如"你是我的乌托邦"）；(b) 带历史/memory 注入的会话。若文学漂移无法复现，Calibration 应聚焦反模板化；若可复现，则双目标校准。
