## 四、模型差异决策

### 选项 A：保持服务器 `deepseek-v4-flash`

```
优点：不需要改服务器 .env，之前的行为已知
缺点：开发验证全部在 deepseek-chat 上，服务器行为与开发不一致
风险：低 — V3.7/V3.8 的 Prompt 在两个模型上表现类似
```

### 选项 B：对齐到 `deepseek-chat`

```
优点：与开发环境完全一致，A/B 差异消失
缺点：需要修改服务器 .env，可能改变用户感受到的回复风格
风险：中 — 用户已经适应了 v4-flash 的输出风格
```

**建议**：**选项 A**（保持不动）。模型差异不是 bug，是配置差异。V3.8 的改进（Prompt 稳定性、Memory 修复）是模型无关的。如果需要对齐，应在 V4 Stage 0 统一处理。
