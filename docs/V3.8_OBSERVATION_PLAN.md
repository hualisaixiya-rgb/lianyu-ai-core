## 四、进入 V4 的判断条件

### 必须全部满足（AND）

| # | 条件 | 状态 |
|---|------|:--:|
| 1 | 核心红线指标全部为零（R1-R4） | ⚠️ 仅 1 天数据，待验证 |
| 2 | 至少 3 个观察周期无红线触发 | ⚠️ 需完成 OC-2/3/4 |
| 3 | 趋势指标稳定（无持续恶化方向） | ⚠️ 需多周期对比 |
| 4 | 至少 1 次生产环境部署验证（服务器端） | ❌ 服务器仍为 V3.4 |
| 5 | Profile 确认成功 > 0 且 LongMemory 召回 > 0 | ✅ OC-1 已确认 |
| 6 | 架构文档完整 + 审查流程就绪 | ✅ |
| 7 | V4 设计文档冻结 | ✅ |

### 满足以下任一条件则延后进入 V4

| # | 条件 |
|---|------|
| 1 | 任一红线指标触发 |
| 2 | 趋势指标连续 2 个周期恶化 |
