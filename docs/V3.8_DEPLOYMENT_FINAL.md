## 三、回滚方案

### 方案 A：Git 回退（推荐）

```powershell
cd E:\AI\lianyu-ai-core
git checkout V3.7-stable
nssm restart LianyuAI
nssm restart LianyuTelegram

# 等待 5 秒
Start-Sleep 5

# 验证
curl http://localhost:8000/api/v1/health
curl -X POST http://localhost:8000/api/v1/chat `
  -H "Content-Type: application/json" `
  -d '{"user_id":"rollback-test","message":"你好"}'
```

如果 V3.7 也不满意：

```powershell
# 回滚到 V3.4 最后已知 commit
git checkout <v3.4-commit-hash>
nssm restart LianyuAI
nssm restart LianyuTelegram
```

### 方案 B：数据库回退

```powershell
# 1. 停止服务
nssm stop LianyuAI
nssm stop LianyuTelegram

# 2. 恢复数据库
Copy-Item "E:\AI\backups\lianyu.db.v38-*" "E:\AI\lianyu-ai-core\data\lianyu.db" -Force

# 3. 恢复 .env（如需要）
Copy-Item "E:\AI\backups\.env.v38-*" "E:\AI\lianyu-ai-core\.env" -Force

# 4. Git 回退 + 启动
git checkout <target>
nssm start LianyuAI
nssm start LianyuTelegram
```

### 回滚触发条件

| 条件 | 操作 |
|------|------|
| Health 端点不通 | 立即回滚 |
| Chat 返回空或错误 | 立即回滚 |
| AI 属性暴露（"我不需要睡觉" 等） | 评估后决定（可能只是风格变化） |
| Telegram Bot 不回复 | 检查代理 → 重启 → 如仍不可用则回滚 |
| 服务频繁崩溃 | 立即回滚 |
