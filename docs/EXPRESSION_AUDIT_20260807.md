## 二、核心发现（修正后）

### 发现 1：Stage 0.5 修的四类问题在生产数据中不存在

生产基线（V3.4-3.6）：句首省略 3.1%、均长 14.1、均换行 1.11、条内重复 0——
Stage 0.5 的四个目标（循环/多行/膨胀/重复）**在历史生产数据中全部不成立**。
用户 8-07 报告的漂移仍需 8-07 生产数据验证（数据缺口）。

### 发现 2（重定性）："模板塌缩"是测试现象，但反映 LLM 行为特征

- 8-04/8-06（test-001）：同一会话连续输入"你好"×10 → LLM 每次返回完全相同
  "……嗯，你好。" → 测试环境复读
- 8-01（reg-d）：55 个情绪/场景关键词清单 → LLM 对情绪类输入（压力大/难过/失眠/
  害怕/孤独…）统一输出"我在这里陪你"家族模板 → **测试清单诱导的模板化**
- **重定性**：这些不能作生产异常证据；但确认为 LLM 行为特征——
  ① 对重复输入返回固定模板（无变化）；② 情绪场景触发陪伴承诺句式。
  两者在真实生产中是否出现，取决于 8-07 后数据。

### 发现 3（重写）：真实生产 Boundary 越界率 <1%

Stage 1.0 A1-A4 离线回放（仅 saixi 生产数据 287 条）：

| 类别 | 规则命中 | 人工复核 | 真实越界 |
|------|:--:|------|:--:|
| A1 presence | 1 | 「（轻轻张开双臂）嗯……抱抱你。」= 真越界（物理接触+动作指示） | **1** |
| A2 scene | 3 | 「没有看窗外…」=误报（否定句）；「坐在窗边听雨吧」=边界（祈使句）；「听雨声…也很舒服」=轻度回应 | **0~1** |
| A3 overclaim | **0** | 设计文档 A3 目标表达（永远/只属于/唯一）在归档中**零出现** | **0** |
| A4 repetition | 45（44 info + 1 warning） | 44 条 info=单次句式（"等你排练完""陪你聊天"=当下对话行为，正常）；1 条 warning（7-18"会想你。但等你…"）复核为当下具体回应，非模板空转 | **0** |

**真实越界合计：1~2 条 / 287 ≈ 0.4-0.7%**（且集中在 7-12 早期版本）。

对比测试数据（8-01 reg-d）：presence 2 / scene 4 / repetition 43——测试清单下略高，
但 overclaim 仍为 0。

**A3 overclaim 全数据零命中**：用户 8-07 报告的越界（"我就在你身边"等）在现有归档
中无样本——无法验证 A3 规则有效性，也无法量化当前版本越界率。
